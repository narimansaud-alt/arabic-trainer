# Словарь Мединского курса, том 3: активное задание

Дата фиксации: 2026-08-13

Статус: активно. Это отдельное задание по словарю третьего тома. Оно не отменяет и не заменяет ранее сохранённые задания по правилам и другим томам.

## Цель

Заполнить словарь курса `Мединский курс (Том 3)` строго по фотографиям словаря из папки `C:\Users\user\Desktop\Мединский курс\Третий том\Фото словарь`, сохранив разделение по урокам и существующий пользовательский формат приложения. Архив `C:\Users\user\Downloads\Облако Mail.zip` хранит контрольную копию тех же фотографий.

## Главный источник и ограничения

- Единственный содержательный источник новых слов третьего тома — фотографии внутри указанного архива.
- Рабочий путь к распакованным исходным фотографиям: `C:\Users\user\Desktop\Мединский курс\Третий том\Фото словарь`.
- 2026-08-13 выполнено побайтовое сравнение 44 файлов из рабочей папки и архива по именам, размерам и SHA-256: различий нет.
- Фотографии являются главным документом. Данные из существующей базы, словарей томов 1–2, знаний модели и сторонних источников нельзя использовать для добавления отсутствующих на фотографиях слов.
- Нельзя придумывать слово, перевод, форму, номер урока или связь между словами.
- Нечитаемое место нельзя восстанавливать догадкой. Его нужно отложить как неразрешённое с указанием фотографии и места.
- Фусха используется только для проверки очевидных опечаток и корректности огласовки уже присутствующего на фотографии слова.
- Если в базе исправлена опечатка источника или добавлен отсутствующий харакат, это обязательно заносится в итоговый журнал исправлений: урок, фотография, форма на фото, форма в приложении и краткое основание.
- Все изменения ограничены словарём третьего тома. Правила, словари других томов и книжные материалы не изменяются.

## Обязательный порядок работы

1. До импорта изучить фактическую структуру словарей томов 1 и 2: схему данных, названия полей и разделов, структуру таблиц, карточек и оба режима отображения.
2. Безопасно распаковать архив во временную локальную папку, составить список фотографий и определить границы каждого урока только по самим фотографиям и их порядку.
3. Создать резервную выгрузку текущих данных словаря третьего тома до первой записи.
4. Обрабатывать уроки строго последовательно, начиная с первого и не перескакивая через уроки.
5. Для каждого урока полностью прочитать все относящиеся к нему фотографии и подготовить точную построчную транскрипцию словарных данных.
6. Сверить арабское написание, русский перевод, харакаты, формы и связи ровно с фотографиями.
7. Отдельно зафиксировать каждую редакторскую нормализацию: исправление опечатки или добавление хараката.
8. Внести только проверенный урок в Supabase через отдельную датированную миграцию, ограниченную каноническим названием третьего тома и номером урока.
9. Сразу после записи повторно прочитать данные урока из рабочей базы и сравнить их с подготовленной транскрипцией.
10. Открыть урок в приложении и проверить оба существующих режима словаря. Проверить названия, порядок, таблицы/карточки, арабский и русский текст, огласовку, переносы строк, направление RTL, размеры и отсутствие горизонтального раздвигания страницы.
11. Проверить экран как минимум на настольной и мобильной ширине. Если обнаружена ошибка, исправить и повторить проверки этого урока.
12. Только после успешной проверки данных и обоих экранных режимов переходить к следующему уроку.

## Контрольный журнал по каждому уроку

Для каждого урока должны сохраняться:

- номер урока;
- перечень исходных фотографий;
- число извлечённых словарных записей;
- точная проверенная транскрипция для импорта;
- результат сравнения с существующими данными третьего тома;
- миграция и результат её применения;
- результат обратной проверки из Supabase;
- результат экранной проверки обоих режимов на настольной и мобильной ширине;
- список исправленных опечаток и добавленных харакатов;
- список неразрешённых нечитаемых мест, если они есть.

## Требования к изменениям базы и проекта

- Перед массовой заменой должна существовать восстановимая резервная выгрузка.
- Каждая запись в базу должна подтверждаться фотографией конкретного урока.
- Не удалять спорные существующие данные без сверки с фотографиями.
- Для изменений Supabase создавать датированные миграции в `supabase/migrations/` и применять их к рабочему проекту.
- Не смешивать изменения словаря с изменениями правил или других разделов приложения.
- Перед выпуском проверить синтаксис изменённых скриптов, выполнить `git diff --check`, закоммитить только относящиеся к заданию файлы и развернуть через `main`.

## Условия завершения

Задание завершено только когда:

- обработаны все уроки, представленные в архиве;
- каждый урок подтверждён фотографиями и повторно проверен после записи;
- оба режима словаря проверены на экране для каждого урока;
- выполнен итоговый сквозной аудит словаря третьего тома;
- подготовлен полный журнал всех исправленных опечаток и всех добавленных харакатов;
- отдельно перечислены неразрешённые места, если они остались;
- изменения развернуты и проверены в рабочем приложении.
