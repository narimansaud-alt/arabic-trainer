# Обязательный порядок завершения работы по томам

Дата фиксации: 2026-08-12.

Этот документ уточняет порядок дальнейшей работы и имеет приоритет над прежними планами, в которых первый том мог быть указан как незавершённый.

1. **Первый том завершён.** Повторно извлекать его правила и заново проходить его по источнику не требуется.
2. Полностью завершить второй том по двум обязательным арабским шархам и выполнить его внутренние проверки.
3. После второго тома обработать третий том.
4. После третьего тома обработать четвёртый том.
5. После завершения четвёртого тома провести общий экранный аудит каждого урока и каждой карточки всех четырёх томов по всем ранее установленным требованиям: смысл и русский перевод, арабская грамматика, полная огласовка, окончания, шрифты, размеры, переносы, семантические цвета, таблицы, мобильная прокрутка и отсутствие расширения страницы.

Для третьего и четвёртого томов один и тот же шарх предоставлен в двух форматах — DOC и PDF. Перед обработкой каждого из этих томов необходимо проверить качество извлечения и отображения обоих форматов и выбрать тот формат, который даёт наиболее полный и точный результат. Наличие двух форматов одной работы не означает два независимых шарха и не требует искусственного дублирования source-записей.
