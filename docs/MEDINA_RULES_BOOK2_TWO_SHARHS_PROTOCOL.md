# Обязательное дополнение: два шарха для второго тома

Дата фиксации: 2026-08-12.

Этот документ имеет приоритет над прежним ограничением «использовать только 80-страничный шарх» для второго тома.

## Источники

Каждый урок второго тома необходимо полностью сверять одновременно по двум арабским шархам:

1. `C:\Users\user\Desktop\Мединский курс\Второй том\Podrobny_Sharkh_2_tom.pdf` — 80 страниц.
2. `C:\Users\user\Desktop\Мединский курс\Второй том\Sharkh_na_2_tom_Med_kursa.pdf` — 62 страницы.

Другие материалы и собственные знания модели не могут служить доказательным источником правила.

## Приоритет источников для полного русского шарха

- `Podrobny_Sharkh_2_tom.pdf` является основным полным шархом: его правило, условия, исключения и пояснения имеют приоритет.
- `Sharkh_na_2_tom_Med_kursa.pdf` используется для дополнительных подтверждённых примеров и для тех тем, которым в полном шархе не выделен отдельный раздел.
- Если формулировки источников расходятся, в публичной карточке главным остаётся полный шарх. Отличающаяся формулировка дополнительного шарха сохраняется с явной подписью источника и не подменяет основное правило.
- Работа выпускается пакетами по пять уроков: полный просмотр страниц, миграция, автоматический и экранный контроль, деплой; затем без паузы начинается следующий пакет. Последний пакет содержит урок 31 и итоговый аудит всего тома.

## Поурочный порядок

Для каждого урока, строго по порядку 1 → 31:

1. Определить полные границы урока отдельно в каждом PDF.
2. Прочитать весь урок в обоих шархах, включая продолжения на следующих страницах.
3. Извлечь все подтверждённые учебные положения из обоих источников: نحو, صرف, частицы, формы, употребление слов, исключения и существенные замечания.
4. Сопоставить два шарха друг с другом и с текущими карточками приложения.
5. **До изменения Supabase** дать краткий отчёт по уроку, в котором явно указать:
   - что совпадает в двух шархах;
   - что присутствует только в 80-страничном шархе;
   - что присутствует только в 62-страничном шархе;
   - есть ли прямые смысловые, терминологические или примерные расхождения;
   - что в приложении совпадает, отсутствует, лишнее, ошибочно или находится не в том уроке.
6. После отчёта внести только подтверждённые источниками изменения и выполнить автоматическую проверку урока.
7. Продолжить следующий урок без отдельного запроса разрешения.

## Объединение и расхождения

- Совместимые объяснения двух шархов объединяются в одну понятную карточку без искусственных дубликатов.
- Правило или существенное замечание, подтверждённое только одним шархом, включается с указанием именно этого источника.
- Прямое расхождение нельзя молча сглаживать, выбирать по памяти или исправлять знанием модели. Его нужно явно показать в поурочном отчёте и сохранить так, чтобы различие источников оставалось проверяемым.
- Составленная формулировка `rule_ar` должна быть краткой, точной и полностью огласованной. Она не является цитатой источника.
- Каждый дословный `source_text` хранится отдельно, без исправления, нормализации и добавления харакатов.
- Фрагменты разных PDF сохраняются отдельными строками с точным `source_document`, страницей или диапазоном страниц и порядком фрагмента. Их нельзя смешивать в одном `source_text`.
